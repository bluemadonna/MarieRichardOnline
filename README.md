# MarieRichardOnline.com — инструкция по запуску

## Шаг 1. Настройка базы данных (Supabase)

1. Зайди на https://supabase.com, зарегистрируйся (бесплатно)
2. "New Project" → придумай имя, пароль базы данных (сохрани его куда-нибудь), выбери регион (любой европейский ближе всего)
3. Подожди ~2 минуты, пока проект создастся
4. Слева в меню открой **SQL Editor** → **New query**
5. Открой файл `supabase_setup.sql` из этой папки, скопируй всё содержимое, вставь в редактор и нажми **Run**
   — это создаст две таблицы: `poll_votes` и `guestbook_entries`
6. Слева открой **Project Settings** (шестерёнка) → **API**
7. Скопируй **Project URL** и **anon public** ключ

## Шаг 2. Впиши свои данные в config.js

Открой `config.js` в любом текстовом редакторе и вставь скопированное:

```js
const SUPABASE_URL = "https://твой-проект.supabase.co";
const SUPABASE_ANON_KEY = "твой-длинный-ключ";
```

Сохрани файл. Опрос и гостевая книга заработают сразу после публикации сайта.

## Шаг 3. Публикация на GitHub Pages

1. Зайди на https://github.com, зарегистрируйся, если ещё нет аккаунта
2. Нажми **+** → **New repository**, назови как хочешь (например `marierichardonline`), сделай **Public**, создай
3. На странице репозитория нажми **Add file → Upload files**
4. Перетащи туда ВСЕ файлы из папки сайта (включая images/) и нажми **Commit changes**
5. Зайди в **Settings** репозитория → **Pages** (слева в меню)
6. В разделе "Build and deployment" выбери **Source: Deploy from a branch**, **Branch: main**, папка **/ (root)** → **Save**
7. Подожди 1-2 минуты, обнови страницу — вверху появится ссылка вида `https://твой-ник.github.io/marierichardonline/`

Дальше при любых правках — просто загружай изменённые файлы через тот же **Add file → Upload files** (перезаписывает существующие), сайт обновится за минуту.

## Как удалять спам-записи

1. Зайди на https://supabase.com/dashboard → твой проект
2. Слева **Table Editor**
3. Выбери таблицу `guestbook_entries` (записи гостевой) или `poll_votes` (голоса)
4. Отметь галочкой строку(и) → кнопка **Delete** сверху

Больше никто, кроме тебя (у кого есть логин от Supabase), удалить записи не может — сайт умеет только добавлять и читать.

## Важно про курсор-эффект

Скрипт `fairyDustCursor` подключается с unpkg.com — на GitHub Pages/Cloudflare Pages нет ограничений Neocities, так что он будет работать нормально.
